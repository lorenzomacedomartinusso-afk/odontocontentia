# Base de Conhecimento (Brain)

Esta pasta serve como o "cérebro" adicional da sua IA.

## Como usar
1. Crie arquivos de texto (`.txt`), Markdown (`.md`) ou PDF (`.pdf`) aqui dentro.
2. Escreva o conteúdo que você quer que a IA considere (ex: diretrizes de marca, exemplos de posts, "do's and don'ts", etc).
3. A IA lerá automaticamente todos os arquivos desta pasta e usará esse conteúdo para gerar as próximas narrativas.

## Exemplos de arquivos
- `tom-de-voz.txt`: Regras sobre como o dentista deve falar.
- `exemplos-bons.md`: Exemplos de posts que performaram bem.
- `persona.txt`: Detalhes sobre o público alvo.
